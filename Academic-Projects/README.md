# Academic Engineering Projects

Selected academic work completed during B.Tech Biomedical Engineering.

## 1. Smart Remote Monitoring Module for Paralysis Detection Using IoT Applications

**Focus:** Biomedical instrumentation, sensor integration and remote monitoring concepts.

The project explored a wearable/remote monitoring concept using an Arduino Nano, ESP8266 connectivity, physiological and environmental sensors, and alert components.

**Components discussed in the project**
- Arduino Nano (ATmega328P) and ESP8266
- ADXL335 accelerometer
- ECG and pulse sensing modules
- DS18B20 temperature sensor and DHT11
- SIM800L communication module
- Buzzer / vibration alert

**Conceptual flow:** Sensors → microcontroller → connectivity → remote monitoring platform → alert/notification.
